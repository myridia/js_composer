# AGENTS.md — js_composer

## What this is
A source backup of the popular WordPress plugin WPBakery Page Builder (folder `js_composer`). Served as a backup; a license is required to operate it.

## Stack
- PHP (WordPress plugin)
- WPBakery Page Builder

## Build
No build required — this is a source backup.

## Run
Install the `js_composer` folder as a WordPress plugin (requires a purchased license).

## Structure
- `js_composer/` — the WPBakery plugin source
  - `js_composer.php` — plugin entry point
  - `include/`, `modules/`, `config/`, `assets/`, `locale/` — plugin internals
- `LICENSE.md` — license

## Conventions
- No comments in code unless asked.
- Verify: `php -l js_composer/js_composer.php`.
